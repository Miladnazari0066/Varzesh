# تمرین خانگی — Home Workout PWA

اپلیکیشن کامل تمرین در خانه برای مبتدیان: تایمر فواصل دقیق، سازنده تمرین،
پیگیری پیشرفت، ذخیره‌سازی محلی و رابط فارسی راست‌به‌چپ.

## اجرا

هیچ وابستگی‌ای ندارد و هیچ build‌ای لازم نیست. یک سرور استاتیک کافی است
(به‌خاطر Service Worker و ماژول نبودن اسکریپت‌ها، باز کردن مستقیم فایل کار نمی‌کند):

```bash
# داخل پوشه پروژه، هر کدام که نصب داری:
python -m http.server 8000
# یا
npx serve .
```

بعد در مرورگر:  http://localhost:8000

## دیدن روی موبایل

1. لپ‌تاپ و گوشی را روی همان وای‌فای وصل کن.
2. آدرس شبکه داخلی را پیدا کن:
   - ویندوز: `ipconfig` → IPv4 Address
   - مک/لینوکس: `ip addr` یا `ifconfig`
3. در مرورگر گوشی برو به `http://<آی‌پی-لپ‌تاپ>:8000`
4. برای نصب به‌عنوان اپ (PWA): منوی مرورگر → «Add to Home Screen / افزودن به صفحه اصلی».
   نصب PWA به HTTPS نیاز دارد؛ روی localhost مرورگرها استثنا قائل‌اند، برای گوشی می‌توانی
   از یک تونل HTTPS مثل `npx localtunnel --port 8000` استفاده کنی.

## ساختار

```
index.html          پوسته اپ
css/style.css       طراحی و تم تیره/روشن
js/store.js         ذخیره‌سازی نسخه‌بندی‌شده + خروجی/ورودی JSON
js/i18n.js          دیکشنری فارسی/انگلیسی + اعداد فارسی
js/exercises.js     کتابخانه حرکت‌های پایه
js/audio.js         صدا با Web Audio API + لرزش
js/timer.js         موتور تایمر (state machine + timestamp-based)
js/routines.js      CRUD تمرین‌ها + آمار و تاریخچه
js/ui.js            رندر همه صفحه‌ها
js/app.js           اتصال همه بخش‌ها
sw.js / manifest    PWA و پشتیبانی آفلاین
```

## نکته‌های مهم

- تایمر بر اساس `performance.now()` است؛ توقف/ادامه دقیق است و برگه‌های
  پس‌زمینه باعث خطای انباشته نمی‌شوند (هر فریم حداکثر ۲ ثانیه حساب می‌شود).
- وقتی مرورگر بسته یا صفحه قفل شود، هیچ تایمر وبی تضمین شده کار نمی‌کند —
  این محدودیت همه اپ‌های وب است، نه صرفاً این برنامه.
- حرکت‌های «دستی» (rep-mode) خودشان توسط کاربر تمام می‌شوند؛ تایمر ادعای
  شمارش تکرار ندارد.
- خروجی/ورودی داده‌ها از بخش تنظیمات، با اعتبارسنجی و انتخاب «جایگزینی/افزودن».
